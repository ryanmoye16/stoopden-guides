Privacy

A static site with very little to collect.

Stoopden Guides is HTML and CSS hosted on GitHub Pages. There is no account, no checkout, and no comment form on these pages.

What this site is

Public web pages on GitHub Pages at https://stoopden.com/. The custom domain is set with a CNAME file in this repo.

What we do not collect here

  • No account or mailing-list form on these pages.
  • No payment data. There is no checkout on this site. When Amazon links go live, purchases happen on Amazon.
  • No personal support inbox published on this site.

What third parties may see

GitHub Pages. GitHub hosts the files and may log requests according to GitHub’s own policies.

Fonts. Pages load Fraunces and Inter from Google Fonts. Google may receive your IP address and the page referrer when the font files are fetched. If we later self-host fonts, this paragraph will change.

Amazon (later). When Associates links go live, Amazon will see the click and any purchase under their policies. Disabled “Amazon link coming” controls do not send you to Amazon.

Cookies and analytics

These pages do not set a first-party analytics cookie. We have not added a tracking pixel. Browser storage that GitHub, Google Fonts, or a future affiliate partner uses is outside this HTML.

Contact

This site does not publish a personal inbox. There is no checkout and no order records on these pages.
